# 🏛️ Google Workspace CLI (GWS CLI)

> [!info] Profil Singkat
> **Google Workspace CLI (GWS CLI)** adalah perangkat baris perintah (*command line tool*) open-source yang dirancang untuk mempermudah AI Agent berinteraksi dengan layanan Google Workspace, khususnya Google Drive dan Google Sheets, melalui API resmi Google Cloud.

## 📌 Fungsi & Penggunaan
- Memungkinkan AI Agent membaca, mengunggah, membuat, dan memodifikasi file di Google Drive.
- Memungkinkan pembacaan dan penambahan baris data transaksi pada spreadsheet Google Sheets.
- Memerlukan konfigurasi OAuth 2.0 (Google Cloud Project, OAuth Consent Screen, dan Client ID Desktop).
