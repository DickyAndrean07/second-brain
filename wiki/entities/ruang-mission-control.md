# 🏛️ Ruang Mission Control

> [!info] Profil Singkat
> **Ruang Mission Control** (berevolusi dari Sultan Mission Control) adalah aplikasi portal operasional open-source untuk memantau dan mengelola tim AI otonom secara interaktif dalam lingkungan visual 3D bernuansa lokal Indonesia.

## 📌 Fitur Kunci
- **Visualisasi Office 3D**: Pemetaan status operasional agen secara spasial (workstation kerja, lounge santai saat idle, kamar tidur/lantai atas saat off).
- **Kanban Task Board & Calendar**: Manajemen tugas dan pemantauan pekerjaan berjadwal otomatis.
- **Token Analytics**: Audit konsumsi token LLM per-agen untuk efisiensi biaya.
- **Memory & Folder Explorer**: Antarmuka web untuk menginspeksi file memori dan direktori kerja tanpa perlu terminal SSH.
- **Sistem Keamanan**: Proteksi menyeluruh menggunakan Access Code dan penguncian profil agen tingkat tinggi menggunakan PIN (*Profile Lock*).
