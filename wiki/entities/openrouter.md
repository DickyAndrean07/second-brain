# 🏛️ OpenRouter

> [!info] Profil Singkat
> **OpenRouter** adalah layanan agregator API model bahasa besar (LLM) terpadu yang menyediakan akses ke ratusan model AI dari berbagai vendor (OpenAI, Anthropic, Google, Meta, Mistral, NVIDIA) melalui satu kunci API standar yang kompatibel dengan protokol OpenAI.

## 📌 Peran dalam Setup AI Agent
- Menjadi pilihan ideal untuk pemula karena menyediakan akses mudah ke model-model gratis (misalnya keluarga **NVIDIA Nemotron Super/Ultra 550B**) maupun model berbayar tanpa perlu mendaftar ke banyak penyedia terpisah.
- Memungkinkan penyesuaian model berdasarkan peran agent: model hemat biaya untuk tugas rutin dan model berpikir tingkat tinggi untuk orkestrator (Lead Agent).
