# 🏛️ Obsidian

> [!info] Profil Singkat
> **Obsidian** adalah aplikasi basis pengetahuan dan personal knowledge management (PKM) yang beroperasi di atas file teks murni Markdown lokal. Obsidian menyediakan fitur penautan dua arah (*bidirectional linking*), visualisasi graf keterhubungan (*graph view*), dan dukungan plugin yang luas.

## 📌 Peran dalam Arsitektur AI Agent
- **Long-Term Memory**: Menampung catatan terhubung tentang riwayat kerja, klien, dan proyek agar agent dapat menelusuri konteks masa lalu melalui *associative trails*.
- **Wadah LLM Wiki (Second Brain)**: Menjadi "IDE" tempat AI Agent bertindak sebagai pemrogram dan kurator pengetahuan, membangun perpustakaan konsep, entitas, dan sintesis secara berkelanjutan.
- **Portabilitas & Kontrol Penuh**: Berkas tersimpan murni sebagai file Markdown lokal, bebas dari vendor lock-in dan dapat disinkronkan langsung via Git/GitHub.
