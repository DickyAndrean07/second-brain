# 🏛️ OpenCode

> [!info] Profil Singkat
> **OpenCode** adalah framework open-source untuk pembangunan aplikasi perangkat lunak berbantuan AI. OpenCode bertindak sebagai agen pelaksana rekayasa (*coding executor*) yang mampu membaca repositori kode, menulis modul, menjalankan server lokal, menjalankan pengujian otomatis (*testing*), dan memperbaiki error secara mandiri.

## 📌 Peran dalam AI Team
- Dalam alur pengembangan piranti lunak di [[wiki/sources/video-5-membangun-mission-control-ai-team|Video 5]]:
  - **Lead Engineer Agent** bertindak sebagai perancang strategi dan peninjau (*reviewer*).
  - **OpenCode** bertindak sebagai pelaksana langsung yang menulis dan memperbaiki kode.
- Dapat dihubungkan dengan model cerdas berbayar melalui subscription **OpenAI Codex / ChatGPT Pro** untuk menghasilkan penulisan kode berstandar industri.
- Tersedia sebagai bundle terintegrasi dalam ekosistem [[wiki/entities/hermes-agent|Hermes]].
