# Raw Sources (Layer 1: Immutable Truth)

Folder ini adalah tempat Anda meletakkan semua dokumen sumber asli.
Karakteristik utama:
1. **Immutable**: Agen AI hanya membaca file di sini dan **TIDAK AKAN PERNAH mengubah atau menghapus** file sumber asli.
2. **Format yang didukung**: Markdown (`.md`), teks (`.txt`), PDF, HTML clip, transkrip meeting/podcast, gambar artikel, dll.
3. **Obsidian Web Clipper**: Anda dapat menggunakan ekstensi Obsidian Web Clipper di browser untuk mengkliping artikel web langsung ke folder `raw/`.
4. **Gambar / Lampiran**: Simpan lampiran gambar pada subfolder `raw/assets/`.

Setelah memasukkan file ke folder ini, beri tahu agen di chat (contoh: *"Tolong ingest artikel raw/nama-artikel.md"*).
